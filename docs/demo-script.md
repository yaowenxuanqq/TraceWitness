# 主演示预演

按这个顺序讲 6 到 8 分钟。先执行 `run_mock.bat`，浏览器打开 `http://127.0.0.1:8080/`。本文件是预演稿，演示视频还没有录制。

1. 指出页首 `MOCK_MODE`。说明这条链路不调用真实模型，也不计入 Agent 指标。
2. 看北门事件和工具调用。结论只列出这次工具返回的来源编号。
3. 打开一条人员合并。不可达或旅行时间不够的工单不能批准。待审批的工单可以批准或驳回。
4. 看检索解释。硬过滤发生在算分之前，没有命中时不新建人员。
5. 看非机动车告警。出楼方向没有待确认告警。确认告警后，开门动作仍然是未执行。
6. 看时空轨迹。屋顶点被剔除，同一扇门的中间点不画进折线。证据包可以校验；改过的清单会失败。
7. 看插件。签名失败的 `door-watch` 1.2.0 未加载，也没有核对包内哈希。资源超限的 `crowd-count` 留在候选槽。点一次「回滚到上一版」，在用版本和上一版对调，下面出现一条人工回滚记录。再点「故障注入」，在用版本回到上一版，记录原因是故障。
8. 最后说明评测数字以 `docs/eval-report.md` 为准。Agent 任务完成率和演示视频都还没有测完。
