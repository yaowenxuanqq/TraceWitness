### P1-02：上传接口接受任意 Content-Type，存在同源内容注入风险

**严重级别：** P1，安全问题；当前仅本机监听，因此现实风险受限

**实测证据：**

上传一个 `evil.html`，Content-Type 设置为 `text/html`：

```text
POST /api/media/uploads
status=200
contentType=text/html
GET /api/media/assets/{id}/file
status=200
Content-Type=text/html
X-Content-Type-Options=(空)
```

**影响：**

- 页面允许上传的区域只接受 `video/*,audio/*`，但后端没有验证 MIME、扩展名或文件魔数。
- 如果未来服务暴露到局域网或公网，恶意 HTML/SVG 可能被同一来源加载并执行脚本。
- 当前默认回环监听降低了风险，但不应把未验证文件直接以内联 HTML 返回。

**解决方案：**

1. 服务端只接受 `audio/*` 和 `video/*`。
2. 结合扩展名、MIME 和文件魔数三重校验。
3. 拒绝 `text/html`、`image/svg+xml`、可执行文件和未知类型。
4. 媒体响应增加：

```text
X-Content-Type-Options: nosniff
Content-Security-Policy: default-src 'none'; sandbox
```

5. 如果后续需要非媒体文件，使用独立域名或 `Content-Disposition: attachment`。
6. 增加非法 MIME、伪造扩展名、超大文件和路径穿越测试。

**通过标准：**

- HTML/SVG 上传返回 400。
- 文件内容与声明的媒体类型不匹配时返回 400。
- 媒体响应带 `nosniff`。
- 不存在同源 HTML 执行路径。

2. 至少覆盖：
   - 页面资源。
   - 健康、总览、事件、媒体。
   - 审批成功和重复审批 409。
   - 证据正常/篡改/缺失。
   - 难例标注/导出。
   - 插件回滚。
   - 上传拒绝非法类型。
3. 增加可选浏览器回归：
   - 页面加载。
   - 无 console error。
   - 证据校验。
   - 人员审批。
   - 390px 无横向溢出。

**通过标准：**

- 干净 clone 一条命令执行单元、接口和页面关键回归。
- 任一核心链路失败时退出码非 0。

**通过标准：**

### P2-04：构建依赖优先使用区域镜像

**严重级别：** P2，低

**证据：**

- Gradle distribution 使用华为云镜像。
- Maven 依赖优先阿里云。

**影响：**

- 中国网络环境构建较快。
- 海外评审或镜像故障时，首次构建可能失败。

**解决方案：**

- 保留镜像，但补充官方源回退说明。
- CI 固定可访问的官方源。
- 记录已验证的 Gradle Wrapper SHA-256。

### P2-05：Python HTTP 请求体没有禁止额外字段

**严重级别：** P2，低

**证据：**

- Agent 报告和工具参数已经严格校验。
- `/v1/agent/select-tool` 的顶层请求体包含额外字段时仍返回 200，额外字段被忽略。

**影响：**

- 调用方拼错字段时不会 fail closed。
- 接口契约不够严格，容易出现“请求成功但字段没生效”。

**解决方案：**

1. 使用 Pydantic 请求模型。
2. 设置 `extra="forbid"`。
3. 给 clock、task、tools、tool_results 和 vision 参数定义明确类型。
4. 增加未知字段、错误类型和缺字段测试。

**通过标准：**

- 额外字段返回 400。
- 缺必填字段返回 400。
- 错误类型返回 400。
