# 契约

第 10 周的轨迹、同行和证据包由 Java 计算。不可达门点不进入保留序列。证据包用清单的 SHA-256 校验，缺文件时报错。难例只有标注之后才出现在导出清单里。候选模型对比只记录分数，不训练。

第 9 周的检索和门线告警由 Java 计算。命中和剔除都带解释。出楼方向不产生告警。开门动作保持待人工确认。

第 8 周的人员档案按最短路和旅行时间约束合并。双库分数过近时进入待审批，批准或驳回都写审计。空检索不新建人员。

第 7 周的 Agent 工具由 Java 执行。报告里的 `source_ids` 只能引用本次 run 中工具实际返回的 ID。工具失败、模型失败或引用非法时返回证据不足。
